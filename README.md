## 📖 仓库说明

本仓库采用「**按周组织**」的方式管理每周的实验任务：

- ✅ 清晰地追溯每周的学习轨迹
- ✅ 单独管理每个实验的代码与文档
- ✅ 便于老师/助教快速审查作业

每次提交（Commit）都会留下时间戳和说明，**永远可以回溯到任何一个历史版本**，再也不用担心文件被改坏找不回来。

## 🚀 快速使用

### 第一次把仓库拉到本地（在新电脑上）

```bash
git clone https://github.com/cell389/ncu-portfolio.git
cd ncu-portfolio
```

### 每周交完实验后，提交并推送

```bash
git add .
git commit -m "Week05: 完成 xxx 实验"
git push
```
